# BookNest

BookNest — кітап дүкені және оқу клубының 4 беттік статикалық веб-сайты (1-деңгей).

## Сайт сілтемесі
[Live Demo (GitHub Pages)](https://bagdarlamakamtamasety-a11y.github.io/booknest/)

## Мобильді нұсқадағы кемшіліктер (тестілеу нәтижесі)
1. Экран ені 400px-тен кіші болғанда навигация сілтемелері бір жолға сыймай, шетке шығып кетеді (гамбургер мәзір қажет).
2. `books.html` бетіндегі кесте мобильді экранда көлденең скроллсыз қысылып қалады.
3. Hero бөліміндегі `h1` тақырыбы (`2.5rem`) телефон экранында тым үлкен көрінеді.
